(async) autoDownloadFiles() → {Promise}

Description:

  • 取得cv.exe，回傳cv.exe的絕對路徑

    相容舊公開子路徑w-docx2pdf/src/autoDownloadFiles.mjs，內部轉呼叫ensureBins： 首次使用時下載(或自鏡像取得)並以bin/manifest.json校驗，之後自快取取得，不再於安裝時(postinstall)下載，亦不再自行定位src/cv.exe， 快取位置與離線部署見README〈外部執行檔〉

    因cv.exe只能用於Windows作業系統，故調用前須自行檢核作業系統

Source:
  • autoDownloadFiles.mjs, line 30
Example
import autoDownloadFiles from 'w-docx2pdf/src/autoDownloadFiles.mjs'

async function test() {

    let { fpExe } = await autoDownloadFiles()

    console.log('fpExe', fpExe)
    // fpExe D:\xxx\node_modules\w-docx2pdf\bin-cache\<sha256>\cv.exe
}
test()
    .catch((err) => {
        console.log('catch', err)
    })

回傳Promise，resolve回傳執行檔路徑物件，內含fpExe為cv.exe的絕對路徑字串，reject回傳帶code之Error

ensureBins(optopt) → {Promise}

Description:

  • 取得本套件之外部執行檔(cv.exe): 首次使用時下載(或自鏡像取得)並以bin/manifest.json之SHA-256與大小校驗, 之後自快取取得(亦校驗) 規格: 外部執行檔之存放下載校驗與離線(制式規格)§6; 實作為wsemi之fsEnsureBins, 本套件不另寫下載、快取、鏡像、校驗 環境變數: W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE, 見README〈外部執行檔〉

Source:
  • ensureBins.mjs, line 35
Example
import ensureBins from 'w-docx2pdf/src/ensureBins.mjs'

async function test() {

    //部署前預先取得, 亦可於連網機器設W_BIN_CACHE後呼叫以備離線鏡像
    let bins = await ensureBins()
    console.log(bins['cv.exe'])
    // => D:\xxx\node_modules\w-docx2pdf\bin-cache\<sha256>\cv.exe

}
